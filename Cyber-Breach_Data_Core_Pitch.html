Cyber-Breach: Data Core

이 문서는 동아리 게임 개발 프로젝트(4~6주)를 위한 2D 웹 기반 서바이버라이크 게임의 핵심 구조, 차별화 요소, 그리고 현실적인 개발 스코프를 정의합니다. 플레이어는 메인프레임에 침투한 해커 프로그램이 되어, 끝없이 몰려오는 백신과 ICE를 물리치며 데이터를 탈취해야 합니다.

프로젝트 핵심 목표

  • 🎯 핵심 루프: 이동, 자동 공격, 레벨업, 빌드 구성
  • 🔥 차별화: 보안 노드 점령 (위험/보상 극대화)
  • ⏱️ 스코프: 4-6주 내 5분 MVP 및 10분 데모 완성
  • 💻 기술 스택: TypeScript + Phaser 3

📊 서바이버라이크 장르 분석 및 차별화

유사 게임들과의 비교를 통해 Cyber-Breach가 집중해야 할 게임성(포지셔닝)을 확인합니다. 차트의 데이터 포인트를 호버하여 각 게임의 특징을 확인하세요.

🦇 Vampire Survivors

장르의 원형. 메타 프로그레션(영구 성장)과 무기 조합(진화)이 핵심. 게임플레이 자체는 단순한 이동에 집중됨.

🥔 Brotato

웨이브 기반 구조와 상점 시스템. 좁은 맵에서의 극단적인 빌드 자유도와 액션성이 강조됨.

🔫 20 Minutes Till Dawn

수동 조준 및 재장전 시스템 도입. 액션의 밀도가 매우 높고 피지컬을 요구함.

TARGET

💻 Cyber-Breach (본 프로젝트)

이동/자동공격의 캐주얼함을 유지하되, '노드 해킹(거점 방어)'이라는 맵 기믹을 통해 플레이어에게 능동적인 위험 감수(Risk & Reward)를 유도.

⚙️ 핵심 시스템: 보안 노드 해킹

서바이버라이크의 지속적인 이동 흐름을 해치지 않으면서 거점 점령을 구현하는 방법에 대한 디자인 해결책입니다.

"Drive-By Hacking" (누적형 거점 점령)

기존 게임의 가만히 서 있어야 하는 점령(예: 오버워치 화물)은 서바이버라이크의 카이팅(도망치며 공격) 룰과 충돌합니다. 이를 해결하기 위해 노드 범위 내에 머물면 해킹 게이지가 차오르고, 범위를 벗어나도 게이지가 초기화되지 않는 방식을 채택합니다.

  • ✔️ Risk: 노드 주변에는 엘리트 적(방화벽)이 스폰되어 난이도 상승.
  • ✔️ Reward: 해킹 100% 달성 시 즉시 다량의 경험치 큐브와 '데이터 상자(무기 업그레이드)' 드롭.
  • ✔️ Flow: 적이 너무 많아지면 노드 밖으로 도망쳐 적을 유인한 뒤, 다시 돌아와 해킹을 재개하는 전략적 카이팅 유도.

주차별 개발 로드맵

🎯 목표 스코프 정의

[MVP] 5분 데모 3주차

  • 캐릭터 1종 (기본 이동)
  • 무기 4종 / 패시브 4종
  • 적 4종 (기본, 원거리, 자폭, 탱커)
  • 보안 노드 시스템 (단일 스폰)
  • 기본 무한 루프 맵 (단색 배경 격자)

[베타] 10분 빌드 5주차

  • 5분, 10분대 보스 스폰 시스템
  • 무기 진화(조합) 시스템 2종 추가
  • 사운드 효과 (BGM 1, SFX)
  • UI 폴리싱 (데미지 텍스트, 레벨업 창)

[위험/과욕] 제외 권장 배제

인벤토리 시스템, 복잡한 해킹 미니게임(퍼즐), 멀티플레이, 랜덤 맵 생성(절차적 맵).

🛠️ 기술 및 에셋 요구사항 (Phaser 3 + TS)

🕹️ 구현 난이도 매트릭스

LOW

이동 및 자동 사격: Phaser의 Arcade Physics로 쉽게 구현. 가장 가까운 적 타겟팅 알고리즘.

LOW

아이템 픽업: 오버랩 이벤트 처리. 자석 효과(Tween) 구현.

MED

보안 노드 로직: 플레이어와의 거리 측정, 게이지 UI 업데이트, 특정 범위 내 몹 스폰 로직 분리.

MED

업그레이드 선택 UI: 게임 일시정지 로직과 데이터 배열 셔플링을 통한 랜덤 3택 시스템.

HIGH

최적화 (500+ 적): 객체 풀링(Object Pooling) 필수. 단순 Physics 대신 커스텀 이동 로직 필요할 수 있음.

🎨 픽셀 아트 최소 에셋 (16x16 or 32x32)

  • ✔️ 플레이어 (대기/이동 2프레임)
  • ✔️ 적 4종 (기본 애니메이션)
  • ✔️ 보스 1종 (크기 2배)
  • ✔️ 발사체 (총알, 레이저 빔)
  • ✔️ 경험치 큐브 (색상별 3종)
  • ✔️ 바닥 타일 (테크노 그리드 1종)
  • ✔️ 보안 노드 (비활성/활성 상태)
  • ✔️ UI 아이콘 (무기 4, 패시브 4)

🤖 AI 에이전트 개발 워크플로우

  • 기획/스코프 제어: ChatGPT (문서화, 로직 흐름 검증)
  • 코드 구현 (TS/Phaser): Cursor IDE / Codex (객체 풀링, 충돌 처리 보일러플레이트 작성 위임)
  • 에셋 생성: PixelLab / AI Image (기본 스프라이트 시트 생성 후 직접 다듬기)
  • * 주의: 게임 밸런싱(수치 조정)과 물리 엔진 세부 튜닝은 AI에 전적으로 위임하지 말고 직접 테스트하며 맞출 것.
